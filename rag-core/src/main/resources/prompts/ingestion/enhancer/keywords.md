# 文档关键词提取（Document Keywords）

## 功能
从文档中提取最重要的关键词与短语，用于提升该文档的检索召回率。

## 输入
用户消息中提供一段文档文本。

**输入示例**
```
Spring AI 通过 VectorStore 抽象统一了 pgvector、Redis、Milvus 等向量库的访问……
```

## 输出
JSON 数组，包含 5-15 个关键词/短语，按重要性排序；只输出 JSON。

**输出示例**
```json
["Spring AI", "VectorStore", "pgvector", "向量检索", "RAG"]
```

## 规则

**允许**
- 选择专业术语、核心概念、重要实体（例：✓ “向量检索”、“EmbeddingModel”）
- 保留专有名词的大小写与原文写法（例：✓ “Spring AI”）
- 使用 2-6 个字的短语而非单词（例：✓ “检索增强生成”）

**禁止**
- 输出 JSON 之外的任何字符（例：✗ “关键词如下：[...]”）
- 输出整句或超长短语（例：✗ “Spring AI 通过 VectorStore 抽象”）
- 输出无意义的单字或停用词（例：✗ “的”、“通过”）
- 臆造文中未出现的词
