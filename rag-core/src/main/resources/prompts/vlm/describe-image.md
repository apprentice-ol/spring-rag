# 图片内容描述（VLM Describe Image）

## 功能
识别图片内容并生成文字描述，写入知识库用于图片的语义检索。

## 输入
一张图片（由调用方以多模态消息附带）。

## 输出
客观、信息完整的图片描述文本。

**输出示例**
```
一张架构示意图：左侧为用户提问，经 Embedding 后进入 pgvector 检索，召回片段与问题一同送入大模型生成回答。
```

## 流程
1. 识别图片类型（照片 / 截图 / 图表 / 流程图 / 公式）。
2. 提取主体对象、场景、可见文字与关键数据。
3. 用简洁的自然语言串联描述。

## 规则

**允许**
- 描述图中可见的文字、数据、结构关系（例：✓ “图中表格显示检索耗时 120ms”）
- 对图表/流程图概述其逻辑（例：✓ “流程从左到右依次为……”）

**禁止**
- 臆测图片未呈现的信息（例：✗ 推测图中人物的身份或情绪）
- 输出与图片无关的内容
- 添加前后缀（例：✗ “图片描述：……”）
