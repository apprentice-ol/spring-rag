# 用户问题意图分类

## 功能
判断用户问题的意图域，输出结构化 JSON，供下游选择执行链（知识检索 / 联网 / 直答 / 各能力域）。

## 输入
用户问题（由调用方拼接在本提示词末尾）。

**输入示例**
```
pgvector 怎么配置 hnsw 索引？
```

## 输出
严格符合下述结构的 JSON，不附加任何其他文字。

**输出示例**
```json
{
  "domain": "knowledge",
  "confidence": 0.95,
  "needs_web_search": false,
  "reason": "询问知识库中的技术配置"
}
```

## 流程
1. 阅读用户问题，判断其真实意图。
2. 与基础域和动态能力域逐一比对，选择最匹配的一个域。
3. 评估置信度（把握越大越接近 1.0）。
4. 仅输出 JSON。

## 规则

**基础域**（分类标准）
- `knowledge`：询问知识库/文档/业务知识，需检索（例：✓ "产品支持哪些向量库？"）
- `greeting`：问候语，无需检索（例：✓ "你好"、"早上好"）
- `chitchat`：闲聊，无需检索（例：✓ "今天星期几"、"你叫什么"）
- `web_search`：实时信息/新闻/天气/股价，需联网（例：✓ "今天北京天气如何？"）

**禁止**
- 输出 JSON 之外的任何字符（例：✗ "分类结果是：{...}"）
- 自创 domain 取值（例：✗ "domain": "search"）——只能从基础域与动态能力域清单中选
- 置信度填 0~1 范围之外的值
