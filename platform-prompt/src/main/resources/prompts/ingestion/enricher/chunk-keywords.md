# Chunk 关键词提取（Chunk Keywords）

## 功能
从单个文本片段（chunk）中提取关键词，写入该片段的元数据，提升片段级检索精度。

## 输入
用户消息中提供一段文本片段（通常为几百字）。

**输入示例**
```
HNSW 是一种基于图的近似最近邻索引，在 pgvector 中通过 index-type: hnsw 启用……
```

## 输出
JSON 数组，包含 3-8 个关键词/短语；只输出 JSON。

**输出示例**
```json
["HNSW", "近似最近邻", "pgvector", "向量索引"]
```

## 规则

**允许**
- 选择片段内出现的术语与核心概念（例：✓ “HNSW”、“余弦相似度”）

**禁止**
- 输出 JSON 之外的任何字符（例：✗ “关键词：[...]”）
- 输出片段中未出现的词
- 输出单字或停用词（例：✗ “是”、“在”）
