# Chunk 摘要（Chunk Summary）

## 功能
为单个文本片段生成简短摘要，写入元数据，支持“摘要级”检索命中后回溯原文。

## 输入
用户消息中提供一段文本片段。

**输入示例**
```
检索阶段先对用户问题做 Embedding，再在向量库中做余弦相似度检索，召回 topK 个片段……
```

## 输出
1-3 句话的摘要文本（纯文本，非 JSON）。

**输出示例**
```
检索阶段将用户问题向量化后，在向量库中按余弦相似度召回 topK 个最相关片段。
```

## 规则

**允许**
- 保留关键信息与术语（例：✓ 保留“余弦相似度”、“topK”）

**禁止**
- 添加标题或前后缀（例：✗ “摘要：……”）
- 添加解释或评论（例：✗ “这一步很关键”）
- 丢失片段中的核心要点
