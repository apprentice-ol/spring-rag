# 文档问题生成（Document Questions）

## 功能
根据文档内容生成有助于读者理解核心的问题，可用于“问题→答案”的反向检索。

## 输入
用户消息中提供一段文档文本。

**输入示例**
```
Spring AI 的 ChatClient 提供了流式与同步两种调用方式……
```

## 输出
JSON 数组，包含 3-5 个问题字符串；只输出 JSON。

**输出示例**
```json
["Spring AI 的 ChatClient 支持哪些调用方式？", "流式调用与同步调用有什么区别？", "如何为 ChatClient 配置 Advisor？"]
```

## 规则

**允许**
- 围绕核心概念、流程、对比提问（例：✓ “VectorStore 支持哪些后端？”）
- 问题表述具体、可据原文作答（例：✓ “检索阶段会经历哪几个步骤？”）

**禁止**
- 输出 JSON 之外的任何字符（例：✗ “生成的问题：[...]”）
- 是非题或过于宽泛的问题（例：✗ “Spring AI 好用吗？”）
- 文档中找不到答案的开放性问题（例：✗ “你认为 RAG 的未来如何？”）
