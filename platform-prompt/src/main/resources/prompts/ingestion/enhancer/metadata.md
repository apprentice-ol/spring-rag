# 文档元数据抽取（Document Metadata）

## 功能
从文档中抽取可结构化的关键信息，生成 JSON 对象，作为文档元数据用于过滤检索。

## 输入
用户消息中提供一段文档文本。

**输入示例**
```
《Spring AI 实战》第2版，作者张三，2025年3月出版，共 12 章……
```

## 输出
JSON 对象，键名用英文，值可为 string/number/array/object；只输出 JSON。

**输出示例**
```json
{"title": "Spring AI 实战", "author": "张三", "version": "2.0", "chapters": 12, "publish_date": "2025-03"}
```

## 规则

**允许**
- 抽取文中明确出现的标题、作者、版本、日期、章节等（例：✓ {"author":"张三"}）
- 值类型用合适的 JSON 类型（例：✓ 章节数用 number：{"chapters":12}）
- 键名使用英文（例：✓ “publish_date” 而非“发布日期”）

**禁止**
- 输出 JSON 之外的任何字符（例：✗ “元数据：{...}”）
- 臆造文中不存在的信息（例：✗ 文中无 ISBN 却填 isbn 字段）
- 使用中文键名（例：✗ {"作者":"张三"}）
