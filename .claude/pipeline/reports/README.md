# 流水线报告与台账（.claude/pipeline/reports/）

本目录是流水线执行证据的**落盘区**。机制约定见全局 dev-loop skill「执行台账」。

## 结构

```
.claude/pipeline/reports/
├── runs/<runId>/            # 每次流水线执行一个目录
│   ├── summary.md           # 活台账（边跑边写；模板见下）
│   ├── stages/<n>-<名>.md   # 各阶段明细报告
│   └── artifacts/           # 原始证据（apifox 报告/截图/日志摘录；大文件可引用外部路径）
├── apifox/                  # Apifox 跑批原始报告（CLI 产出 json/junit）
└── tmp/                     # 临时诊断产物（可随时清）
```

- **runId 约定**：`<YYYY-MM-DD-HHmm>-<target>`（如 `2026-10-11-1030-dev`）；单阶段临时执行用 `adhoc-<日期>`
- **对话只出摘要，明细一律落盘**；中断后从 summary 的「恢复点」续跑

## 阶段报告模板（stages/&lt;n&gt;-&lt;名&gt;.md，统一格式；直接结果必须原文留痕）

```markdown
# 阶段 N · <名称> 报告

- 时间: <HH:mm> ｜ 命令: `<原文命令>`
- **直接结果**（原文摘要，关键行粘贴——不转述）:
  ```
  <原始输出的关键行>
  ```
- 截图 / 证据: `artifacts/<文件名>`（凡 UI / 页面类验证必截图：截结果态、每用例至少 1 张）
- 门禁: PASS / FAIL（对照该阶段门禁标准）
- 下一步: <动作 / 询问用户>
```

- 一天可多次执行：每次独立 `runs/<runId>/` 目录；**历史 run 只读**（不改写，作审查基线）
- summary 只放结论 + 证据引用；原始输出/截图一律留 stages/ 与 artifacts/

```markdown
# 流水线执行报告 — <日期>（<一句话主题>）

## 关键结论
- ...

## 已知问题豁免（如有，注明确认人）
- ...

## 回滚锚点 / 现场
- ...

## 恢复点（中断时）
- 下次从阶段 N 继续
```
